ALFIAN TOUR KWITANSI PWA

Isi:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- og-image.jpg

Cara pakai:
1. Upload seluruh isi folder ini ke hosting HTTPS.
2. Hosting GRATIS bisa memakai GitHub Pages, Cloudflare Pages, Netlify, atau layanan static hosting HTTPS lain.
3. Buka URL dari HP.
4. Android Chrome/Edge: banner/tombol "Instal Aplikasi" akan muncul bila browser memenuhi syarat.
5. iPhone/iPad Safari: Share > Tambahkan ke Layar Utama.
6. Setelah halaman pernah terbuka dan service worker selesai cache, aplikasi dapat digunakan offline.
7. Data kwitansi tetap tersimpan pada perangkat melalui localStorage.

PENTING UNTUK PREVIEW WHATSAPP:
- Preview WhatsApp hanya dapat mengambil metadata dari URL publik yang dapat diakses internet.
- File lokal (file://) tidak bisa menghasilkan preview WhatsApp.
- Setelah dipublish, sebaiknya ubah og:url/canonical menjadi URL final Anda.
- og-image.jpg sudah disediakan ukuran 1200x630.
